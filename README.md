# Accademia Draconica — Il sentiero del cavaliere

Sito statico (HTML, CSS, JavaScript) ad accesso riservato: schermata di presentazione, login con utente e password, contenuti cifrati in `vault/vault.json`.

## Pubblicare su GitHub Pages
1. Carica il contenuto di questa cartella in un repository.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Il sito sarà su `https://TUO-UTENTE.github.io/NOME-REPO/`.

Per gestire gli iscritti usa la cartella privata `accademia-draconica-PRIVATO` (non va caricata): vedi `LEGGIMI.txt` al suo interno.
